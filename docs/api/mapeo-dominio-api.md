# API - Caraxes

|---|---|---|
| caraxes.crear(...) | POST | /api/caraxes |
| caraxes.get(...) | GET | /api/caraxes/{id} |
| caraxes.publicar(...) | PUT | /api/caraxes/{id}/publicar/{kanez} |
